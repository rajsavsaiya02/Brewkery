# Brewkery 🍺

Brewkery is an Android application built using Kotlin, Jetpack Compose, and modern Android architecture guidelines.

## Features & Tech Stack
- **Language**: [Kotlin](https://kotlinlang.org/)
- **UI Framework**: [Jetpack Compose](https://developer.android.com/jetpack/compose)
- **Build System**: Gradle (Kotlin DSL)
- **Minimum SDK**: Android 8.0 (API 26+)

## Project Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/rajsavsaiya01/Brewkery.git
   ```
2. Open the project in **Android Studio**.
3. Sync Gradle and run the app on an emulator or physical Android device.
